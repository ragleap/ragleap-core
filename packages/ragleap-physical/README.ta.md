# ragleap-physical

**நிலை: ப்ரீ-ஆல்பா. சிமுலேஷன் மட்டும். இங்கு எதுவும் உண்மையான வன்பொருளைக் கட்டுப்படுத்தாது.**

RagLeap-இன் AI ஊழியர்களை திறந்த மூல (open-source) சிமுலேட்டர்களுடன் இணைக்கும் ஒரு சிறிய நூலகம் (library); இதனால் மக்கள் பாதுகாப்பாக உருவாக்கவும் சோதிக்கவும் முடியும். கவனிப்பதே முதலில். ஒவ்வொரு செயலும் ஒரு முன்மொழிவு, ஒரு ஒப்புதல், மற்றும் ஒரு பாதுகாப்பு வரம்பு (safety envelope) வழியாகச் செல்லும்; அந்த வரம்பு பிரிட்ஜில் (bridge) ஒரே இடத்தில் உள்ளது. மாடலால் வரம்புகளை மாற்ற முடியாது.

## இன்று என்ன வேலை செய்கிறது (எது செய்யவில்லை)

- கவனிப்பு மற்றும் முன்மொழிவு வடிவங்கள் (v0), நான்கு திறன் நிலைகள், பாதுகாப்பு வரம்பு, சரியாக அந்த முன்மொழிவுடன் பிணைக்கப்பட்ட ஒப்புதல்கள், dry run, விளைவுச் சரிபார்ப்பு, மற்றும் ஒப்புதல் தேவைப்படாத ஒரு நிறுத்தம் (stop). ஒரு சிறிய உள்ளமைந்த ஒற்றை-மூட்டு சிமுலேட்டருடன் (standard library மட்டும்) சோதிக்கப்பட்டது.
- ஒரு AI முகவருக்கு (agent) சரியாக நான்கு கருவிகள்: மூலங்களின் பட்டியலைப் பெறுதல், ஒரு கவனிப்பைப் பெறுதல், வரம்பை (envelope) பெறுதல், ஒரு செயலை முன்மொழிதல். இவற்றில் எதுவும் ஒப்புதல் அளிக்கவோ, செயல்படுத்தவோ, நிறுத்தவோ (stop), வரம்பை மாற்றவோ முடியாது. ஒரு சிறிய MCP சர்வர் (standard library, இயல்பாக loopback, விருப்பத்திற்குரிய bearer token) இவற்றை வழங்குகிறது. அதிகாரப்பூர்வ MCP Python SDK-க்கு (`mcp>=1.28,<2`) எதிராகச் சோதிக்கப்பட்டது. RagLeap-இன் சொந்த MCP கிளையண்ட் படிக்கப்படவும் இல்லை, சோதிக்கப்படவும் இல்லை: அதில் மாற்றங்கள் தேவைப்படலாம் (எடுத்துக்காட்டாக HTTPS).
- MuJoCo அடாப்டர்கள் விருப்பத் துணைத்தொகுப்பாக (extra): ஒன்று கவனிப்பு-மட்டும், மற்றொன்று சிமுலேஷனில் `set_position_target`-ஐப் பின்பற்றும் servo அடாப்டர்; இரண்டும் பிரிட்ஜ் வழியாக மட்டுமே.
- பணியிட வரம்புகள்: x, y, z-இல் ஒரு பெட்டி; கண்காணிக்கப்படும் ஒவ்வொரு புள்ளியும் அதற்குள் இருக்க வேண்டும். தொடக்க நிலையிலும், dry run-இலும், உண்மையான இயக்கத்திலும் சிறு துண்டுகளாக மீண்டும் சரிபார்க்கப்படும். பணியிடம் அமைக்கப்பட்டு, அடாப்டரால் நிலைகளைத் தெரிவிக்க முடியாவிட்டால், அனைத்தும் நிராகரிக்கப்படும். இரண்டு-இணைப்பு கை மாடல் (உள்ளமைந்த மாற்று மற்றும் MuJoCo) இதைச் சோதிக்கிறது.
- ஒரு சிமுலேட்டட் இயந்திரக் கருவி (கருவித் தேய்மானம்): AI ஒரு கருவி ஈடுசெய்தலை (tool offset) மட்டுமே, மைக்ரோமீட்டரில், ஒரு வரம்புக்குள் (envelope) சரிசெய்ய முடியும் (எல்லை, படி அளவு, மாற்றங்களுக்கு இடையிலான குறைந்தபட்ச இடைவெளி). கருவியை மாற்றுவது மனிதச் செயல்; அது ஒரு கட்டளை அல்ல. இது கற்பனை எண்கள் கொண்ட மாடல்; உண்மையான இயந்திரத்தைப் பற்றி எதுவும் கூறாது.
- சுயாதீன மதிப்பாய்வுக்குப் பிறகு வலுப்படுத்தப்பட்டது (CHANGELOG பார்க்கவும்): கடுமையான உள்ளீடு மற்றும் கணிப்புச் சரிபார்ப்புகள், சுய-ஒப்புதல் இல்லை.
- மூன்று-மூட்டு கை மாடல் (`examples/robots/`-இல் MuJoCo XML, கூடவே ஒரு உள்ளமைந்த மாற்று), ROS நிறுவல் தேவைப்படாத ஒரு ஆஃப்லைன் ROS 2 கவனிப்பு-மட்டும் மாக் (mock), மற்றும் `benchmarks/`-இல் ஒரு திரும்பச் செய்யும் தன்மை (repeatability) சோதனை (நிறுவப்பட்ட ஒரே சூழலுக்குள் துல்லியமான மறு இயக்கம்; வெவ்வேறு இயந்திரங்களுக்கு இடையே திரும்பச் செய்யும் தன்மை உறுதியளிக்கப்படவில்லை).
- ஒரு ஆபரேட்டர் கன்சோல் (`ragleap_physical.console`): பிரிட்ஜின் மனிதப் பக்கம். பெயரிடப்பட்ட ஒருவர் நிலுவையிலுள்ள முன்மொழிவுகளைப் பார்க்கிறார், சரியாக அந்த digest-ஐ ஒப்புதல் அளிக்கிறார், செயல்படுத்துகிறார், மேலும் நிறுத்தலாம் (stop). loopback மட்டும், ஒருவருக்கு ஒரு token, ஒப்புதல் அளிப்பவரின் பெயர் token-இலிருந்தே வரும், கோரிக்கையிலிருந்து ஒருபோதும் அல்ல. இது ஒரு கருவி அல்ல: AI-ஆல் இதை அடைய முடியாது.
- இரண்டு கவனிப்பு-மட்டும் தொழில்துறை மாக்குகள், நெட்வொர்க் இல்லாமல், உண்மையான மீட்டரோ இயந்திரமோ இல்லாமல்: ஒரு சிமுலேட்டட் ஆற்றல் தளம் (energy site), மற்றும் கடுமையான வரம்புகளுடன் ஒரு MTConnect ஆவண வாசிப்பான் (இது DTD-களையும் entity-களையும் நிராகரிக்கிறது, அளவுக்கு உச்சவரம்பு வைக்கிறது). இந்த அடாப்டர்கள் கவனிப்பு-மட்டும்: நீங்கள் கொடுக்கும் ஆவணங்களை மட்டுமே படிக்கின்றன, எதையும் அனுப்புவதில்லை. `docs/industry/observe-only-adapters.md` மற்றும் முதல்-மணிநேர வழிகாட்டி `docs/first-hour.md` பார்க்கவும்.
- கட்டப்படாதவை: இரண்டாவது சிமுலேட்டர், உண்மையான வன்பொருள், Java மற்றும் npm கிளையண்டுகள்.
- சிமுலேஷன் என்பது யதார்த்தம் அல்ல. தேர்ச்சி பெற்ற சிமுலேஷன் சோதனையை ஒரு உண்மையான இயந்திரத்திற்கான ஆதாரமாகக் கருத வேண்டாம்.

## எப்போதும் வரம்புக்கு வெளியே

உயிர்-பாதுகாப்பு அமைப்புகள், மருத்துவச் சாதனங்கள், பொதுச் சாலைகளில் செல்லும் வாகனங்கள், ஆயுதங்கள், மற்றும் சுதந்திரமான வன்பொருள் பாதுகாப்பு நிறுத்தம் இல்லாமல் மக்களுக்குத் தீங்கு விளைவிக்கக்கூடிய எதுவும்.

## முயன்று பாருங்கள்

```
pip install -e ".[test]"          # core only, standard library
pip install -e ".[mujoco,test]"   # with the optional MuJoCo adapter
pip install -e ".[test,interop]"  # also runs the MCP SDK interop test
pytest
python examples/demo_fake.py
python examples/two_link_workspace_demo.py
```

பாதிப்புகளை (vulnerabilities) களஞ்சியத்தின் Security tab வழியாகத் தனிப்பட்ட முறையில் தெரிவிக்கவும் (`SECURITY.md` பார்க்கவும்).
