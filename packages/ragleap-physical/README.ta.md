# ragleap-physical

**நிலை: ப்ரீ-ஆல்பா. சிமுலேஷன் மட்டும். இங்கு எதுவும் உண்மையான வன்பொருளைக் கட்டுப்படுத்தாது.**

RagLeap-இன் AI ஊழியர்களை திறந்த மூல (open-source) சிமுலேட்டர்களுடன் இணைக்கும் ஒரு சிறிய நூலகம் (library); இதனால் மக்கள் பாதுகாப்பாக உருவாக்கவும் சோதிக்கவும் முடியும். கவனிப்பதே முதலில். ஒவ்வொரு செயலும் ஒரு முன்மொழிவு, ஒரு ஒப்புதல், மற்றும் ஒரு பாதுகாப்பு வரம்பு (safety envelope) வழியாகச் செல்லும்; அந்த வரம்பு பிரிட்ஜில் (bridge) ஒரே இடத்தில் உள்ளது. மாடலால் வரம்புகளை மாற்ற முடியாது.

## இன்று என்ன வேலை செய்கிறது (எது செய்யவில்லை)

- கவனிப்பு மற்றும் முன்மொழிவு வடிவங்கள் (v0), நான்கு திறன் நிலைகள், பாதுகாப்பு வரம்பு, சரியாக அந்த முன்மொழிவுடன் பிணைக்கப்பட்ட ஒப்புதல்கள், dry run, விளைவுச் சரிபார்ப்பு, மற்றும் ஒப்புதல் தேவைப்படாத ஒரு நிறுத்தம் (stop). ஒரு சிறிய உள்ளமைந்த ஒற்றை-மூட்டு சிமுலேட்டருடன் (standard library மட்டும்) சோதிக்கப்பட்டது.
- மாடலுக்கான நான்கு கருவிகள் (மூன்று படிக்க-மட்டும், ஒன்று முன்மொழிவை மட்டும் திருப்பித் தருவது) மற்றும் அவற்றுக்கான ஒரு சிறிய MCP சர்வர் (standard library மட்டும், இயல்பாக loopback, விருப்பத்திற்குரிய bearer token). அதன் சொந்த சோதனைகளுடனும் அதிகாரப்பூர்வ MCP SDK கிளையண்டுடனும் சோதிக்கப்பட்டது. **RagLeap-இன் சொந்த MCP கிளையண்டுடன் இன்னும் சோதிக்கப்படவில்லை**; அது HTTPS-மட்டும் என்பதால் `ssl_context` பயன்படுத்தவும் அல்லது முன்னால் ஒரு TLS proxy வைக்கவும்.
- MuJoCo அடாப்டர்கள் விருப்பத் துணைத்தொகுப்பாக (extra): ஒன்று கவனிப்பு-மட்டும், மற்றொன்று சிமுலேஷனில் `set_position_target`-ஐப் பின்பற்றும் servo அடாப்டர்; இரண்டும் பிரிட்ஜ் வழியாக மட்டுமே.
- பணியிட வரம்புகள்: x, y, z-இல் ஒரு பெட்டி; கண்காணிக்கப்படும் ஒவ்வொரு புள்ளியும் அதற்குள் இருக்க வேண்டும். தொடக்க நிலையிலும், dry run-இலும், உண்மையான இயக்கத்திலும் சிறு துண்டுகளாக மீண்டும் சரிபார்க்கப்படும். பணியிடம் அமைக்கப்பட்டு, அடாப்டரால் நிலைகளைத் தெரிவிக்க முடியாவிட்டால், அனைத்தும் நிராகரிக்கப்படும். இரண்டு-இணைப்பு கை மாடல் (உள்ளமைந்த மாற்று மற்றும் MuJoCo) இதைச் சோதிக்கிறது.
- ஒரு சிமுலேட்டட் இயந்திரக் கருவி (கருவித் தேய்மானம்): AI ஒரு கருவி ஈடுசெய்தலை (tool offset) மட்டுமே, மைக்ரோமீட்டரில், ஒரு வரம்புக்குள் (envelope) சரிசெய்ய முடியும் (எல்லை, படி அளவு, மாற்றங்களுக்கு இடையிலான குறைந்தபட்ச இடைவெளி). கருவியை மாற்றுவது மனிதச் செயல்; அது ஒரு கட்டளை அல்ல. இது கற்பனை எண்கள் கொண்ட மாடல்; உண்மையான இயந்திரத்தைப் பற்றி எதுவும் கூறாது.
- கட்டப்படாதவை: இரண்டாவது சிமுலேட்டர், உண்மையான வன்பொருள், Java மற்றும் npm கிளையண்டுகள்.
- சிமுலேஷன் என்பது யதார்த்தம் அல்ல. தேர்ச்சி பெற்ற சிமுலேஷன் சோதனையை ஒரு உண்மையான இயந்திரத்திற்கான ஆதாரமாகக் கருத வேண்டாம்.

## எப்போதும் வரம்புக்கு வெளியே

உயிர்-பாதுகாப்பு அமைப்புகள், மருத்துவச் சாதனங்கள், பொதுச் சாலைகளில் செல்லும் வாகனங்கள், ஆயுதங்கள், மற்றும் சுதந்திரமான வன்பொருள் பாதுகாப்பு நிறுத்தம் இல்லாமல் மக்களுக்குத் தீங்கு விளைவிக்கக்கூடிய எதுவும்.
